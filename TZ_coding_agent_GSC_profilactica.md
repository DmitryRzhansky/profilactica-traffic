# ТЗ для coding-agent: визуальный отчёт по Google Search Console для profilactica.clinic

## Задача

Собрать **самостоятельный клиентский веб-отчёт** по фактической органической видимости сайта за **12.07–11.10.2026 (92 дня)**. Показать на реальных цифрах, что Google-трафик сайта сосредоточен преимущественно вне раздела услуг, а сотни коммерческих и GEO-страниц почти не привлекают переходов. Объяснить, почему перестройка коммерческой архитектуры с корректными 301-редиректами затрагивает сравнительно небольшой объём **текущего Google-трафика**, тогда как информационные публикации **не меняются и не мигрируют**.

Это **срез текущего состояния**, а не SEO-стратегия. Не писать планы работ, предложения по улучшению сайта, прогнозы, KPI на будущее, ожидаемые результаты, сценарии роста, рекомендации для редактуры, список следующих шагов. Не утверждать, что миграция безрисковая или трафик гарантированно не упадёт.

## Репозиторий и оформление

Создать проект **в новой директории/новом репозитории**, который подготовит заказчик. **Не создавать ни страницу `/gsc/`, ни новые файлы, ни коммиты в `DmitryRzhansky/profilactica-competitors`.** Его HTML/CSS/типографика — **только визуальный референс**: `https://github.com/DmitryRzhansky/profilactica-competitors`, в частности `index.html` и `assets/css/report.css`. Не импортировать JS и CSS из старого проекта; новый отчёт должен быть автономным.

Вывод: один аккуратно свёрстанный `index.html` на отдельном проекте, адаптивный, с интерактивными **Chart.js**, локальными ресурсами Chart.js, CSS и JS. Никаких SPA-фреймворков и тяжёлых сборщиков. Предусмотреть читаемую печатную версию/PDF через print CSS. Должно работать при открытии через обычный локальный HTTP-сервер, без серверной аналитики или внешних API.

Визуальный язык референса: Inter, светлая подложка, синие акценты около `#1a7fc4`, белые карточки, тонкие границы, компактная типографика, выверенная сетка и много места собственно данным. Ключевые метрики — очень крупные; остальные подписи — скромные. Использовать контраст для акцентирования нулей и малых значений, но **не красить весь отчёт красным**. Tooltip, оси, данные на графиках — на русском. На телефоне каждая диаграмма читается без горизонтального скролла.

Запрещены: eyebrow/верхние надзаголовки, фразы «в условиях высокой конкуренции», «ключевые инсайты», «точки роста», «стратегическая трансформация», «дорожная карта», шаблонные callout-карточки, искусственные цитаты, эмодзи, декоративные графики, огромный сайдбар и длинные пояснения. Тон: сухой, предельно конкретный, как аудит на основе данных. **Один тезис — один график.**

## Исходные данные и порядок расчёта

Источник истины — экспорт Google Search Console: `https___profilactica.clinic_-Performance-on-Search-2026-10-14.xlsx`. Можно использовать подготовленную компактную структуру `profilactica_gsc_report_snapshot.json` для ускорения разработки, но агент обязан проверить её против исходного XLSX или переданной аналитической таблицы при наличии. Ничего не додумывать и не подменять оценками.

Критически важно **не смешивать знаменатели вкладок**:
- по дням (Chart): **1 744 клика, 205 217 показов, CTR ≈ 0,85%** за 92 дня;
- сумма первой 1000 строк страниц (Pages): **1 749 кликов, 207 809 показов**. Эта таблица используется для сравнений групп URL, и все доли групп рассчитываются от **1 749**;
- `Queries` — урезанная выборка и не связывает запросы со страницами. Не строить недостоверную матрицу запрос → URL.

`Pages` содержит **первые 1 000 строк отчёта**, а не полный список всех URL сайта. Нулевые клики **не** означают отсутствие индексации. Трафик относится только к **Google Web Search**, не ко всей органике и не к Яндексу. Значения CTR и средней позиции нельзя интерпретировать как нынешние места в поиске.

## Структура экрана (без дополнительных разделов)

### 1. Первый экран: масштаб и основной вывод

H1: **«Поисковый трафик profilactica.clinic»**.
Под H1 коротко: «Google Search Console · 12 июля — 11 октября 2026 · 92 дня» (это обычная мета-подпись, не eyebrow).

Большие показатели: **1 744 клика**, **207 кликов на услуги**, **785 страниц услуг без кликов**. Дополнительно небольшими числами **205 217 показов** и **0,85% CTR**.

Сразу под цифрами одна фраза: **«Из 884 страниц услуг 785 не получили ни одного клика за три месяца.»**

### 2. Дисбаланс: страниц много, трафика почти нет

**Главная диаграмма:** горизонтальные 100%-ные stacked bars с одинаковыми группами:
- доля URL в Pages: услуги **884/1000 (88,4%)**, остальные **116/1000 (11,6%)**;
- доля кликов в Pages: услуги **207/1749 (11,8%)**, остальные **1542/1749 (88,2%)**.

Вывести рядом абсолюты, чтобы диаграмма не вводила в заблуждение. Цвета категорий едины в обеих строках. Подпись на одну строку: **«Услуги занимают 88,4% URL в выгрузке, но дают лишь 11,8% кликов.»** Это главный клиентский аргумент.

### 3. Сколько коммерческих URL вообще видимы

**Chart.js bar / stacked bar**: 785 страниц с нулём кликов и 99 страниц хотя бы с одним кликом (внутри 884 услуг). Рядом отдельный компактный горизонтальный bar **613 из 884 URL имеют меньше 10 показов**. Не суммировать эти показатели как взаимоисключающие группы: они пересекаются.

Подпись: **«Большинство коммерческих URL практически не приносит переходов.»**

### 4. GEO — 774 страницы, 144 клика

Два синхронных горизонтальных графика по трём группам: число URL и число кликов, с прямыми подписями у полос:
- Нарколог на дом: **84 URL / 35 кликов**;
- Капельницы на дом: **365 URL / 105 кликов**;
- Вывод из запоя: **325 URL / 4 клика**.

Крупный итог секции: **774 страницы / 144 клика за 92 дня**. Также показать **702 из 774 GEO URL — без кликов**. Не делать один график с общей шкалой «страницы» и «клики» — будет нечитабельно.

### 5. Что действительно даёт трафик

Горизонтальный Chart.js bar **ТОП-5 информационных статей** по кликам (с названиями на человеческом русском, URL выводить на hover/по клику):
- Алкоголь и тестостерон — **312**;
- Почему хочется пить алкоголь каждый день — **274**;
- Безалкогольное пиво: риски и польза — **198**;
- Латентный алкоголизм — **132**;
- Признаки тяжёлой алкогольной болезни — **108**.

Сумма: **1 024 клика**. Подпись: **«Эти пять материалов получили больше кликов, чем все 884 страницы услуг вместе.»** Сохранять значение для текущего периода; не обещать сохранение будущих позиций.

Короткая строка под диаграммой: **«При обновлении структуры раздела услуг адреса и содержимое этих статей остаются без изменений.»**

### 6. Примеры фактической видимости коммерческих страниц

Компактная таблица на 6–8 строк: `Страница | Показы | Клики | Средняя позиция`.
Включить:
- `/uslugi/narkolog-na-dom-v-moskve/` — 7 763 / 13 / 29,38;
- `/uslugi/prokapatsya-ot-alkogolya/` — 5 226 / 0 / 25,35;
- `/uslugi/vyvod-iz-zapoya-kodirovaniem/` — 3 472 / 1 / 35,23;
- `/uslugi/vyzov-narkologa-na-dom-v-zvenigorode/` — 3 402 / 17 / 13,51;
- `/uslugi/vyzov-narkologa-na-dom-v-perovo/` — 1 401 / 0 / 5,50;
- `/uslugi/kodirovaniye-ot-alkogolizma-esperal/` — 1 289 / 0 / 30,35.

Полные адреса открываются по клику, slug в таблице может переноситься или обрезаться с tooltip. Не подавать среднюю позицию 5,50 на нулевых кликах как «успех» или доказательство конкретной ошибки Title.

### 7. Динамика: общий трафик не равен трафику услуг

Один Chart.js line chart с **92 дневными точками кликов по сайту** из листа `Chart` и ненавязчивой скользящей средней 7 дней (расчёт прозрачен). Подпись: **«Трафик Google в целом растёт: 411 кликов за первые 30 дней против 688 за последние 30. Но на страницы услуг пришлось лишь 207 кликов за весь период.»**

Не строить сравнение июня/октября как полных месяцев и не утверждать, что отдельные статьи/услуги обязательно росли: дневных рядов по группам URL нет.

### 8. Последний экран: 301 и сохранение информационного трафика

Без схем-планов, чек-листов, этапов и обещаний. Два чётких факта и короткий вывод:

**«Коммерческие URL: 884 страницы, 207 кликов Google за три месяца.»**
**«Информационные статьи, которые дают основную видимую долю переходов, остаются на прежних адресах.»**

Итог: **«Существующая коммерческая структура приносит мало поискового трафика. Поэтому её можно перестраивать, сохраняя соответствие старых и новых адресов через 301-редиректы. Это снижает риск потери уже существующих входов из поиска; гарантировать отсутствие потерь нельзя.»**

В небольшом футере: «Источник: Google Search Console, поиск Web. 12.07–11.10.2026. По URL — первые 1000 строк выгрузки. Сумма кликов в таблице URL отличается от суммы по дням; проценты внутри URL-среза рассчитаны от 1749. Яндекс, прямые заходы и рекламный трафик не включены.»
